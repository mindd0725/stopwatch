# The Stopwatch

LP가 턴테이블 위에서 돌아가는 스탑워치입니다. `stopwatch.html`을 브라우저로 열면 바로 실행됩니다.

- 시작하면 톤암이 LP 위로 내려앉고 33⅓ RPM으로 회전합니다.
- 120 BPM 박자에 맞춰 숫자, 박자 램프, 마디 진행선이 강조됩니다.
- 버튼을 누를 때마다 배경이 흑백 톤으로 바뀝니다.
- 랩 기록은 LP 트랙리스트(A1, A2 …)로 표시됩니다.
- SOUND를 켜면 바이닐 잡음과 비트가 함께 재생됩니다.

## 단축키

| 키 | 동작 |
| --- | --- |
| `Space` | 시작 / 정지 |
| `L` | 랩 |
| `R` | 재설정 |
| `S` | 사운드 켜기 / 끄기 |
